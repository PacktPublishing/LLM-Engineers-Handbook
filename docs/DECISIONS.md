# Decisions (ADR log)

Architectural decisions for this study and for any work derived from it (Athar, Baligh). One entry per decision. Each chapter's Definition of Done in `BOOK-MAP.md` links its decision log to an entry here.

## When to write an ADR

Write one when a choice is hard to reverse, spans more than one component, or when a reviewer would ask "why this and not the alternative". Keep each entry short and dated.

## Format

```
# ADR-00X: Title

- Status: Proposed | Accepted | Superseded
- Chapter:
- Date:

## Context

## Decision

## Alternatives

- Option A: pros and cons.
- Option B: pros and cons.

## Consequences

- Positive:
- Negative:
- Revisit when:
```
